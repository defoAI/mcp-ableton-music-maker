# Story templates

| Template | Use |
|----------|-----|
| [user_story.md](./user_story.md) | Define what to build |
| [implementation_plan.md](./implementation_plan.md) | Plan how to build it |

Story files are named by a descriptive kebab-case slug derived from the title — the slug *is*
the identifier; there are no numeric IDs. Two files per feature: `<slug>.md` and
`<slug>-impl.md`. Rules and rationale: [../naming-and-pm-guide.md](../naming-and-pm-guide.md).

Status flow `Draft → Ready → In Progress → Done`. Priority P0 (now) / P1 (this week) /
P2 (this month) / P3 (backlog). Size S (<1 day) / M (1–3 days) / L (3+ days, consider
splitting).
