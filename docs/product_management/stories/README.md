# Stories

Feature-level design specs, one `<slug>.md` per feature plus an optional `<slug>-impl.md`.
Naming, shape and lifecycle: [../naming-and-pm-guide.md](../naming-and-pm-guide.md).
Template: [../templates/user_story.md](../templates/user_story.md).

Empty is the healthy state between features. Stories are design artifacts, not an archive —
once a feature ships and the code stands on its own, the story is deleted. Git holds it.
