# Ableton references

Local Markdown copies of the Ableton Live manual chapters and the Live Object Model (LOM) that the Remote Script in `AbletonMusicMaker_Remote_Script/__init__.py` and the tool bodies in `src/tools.rs` rely on. Each file starts with a header table naming its source URL, the date it was fetched and the Live version the page states. The text is Ableton AG's or Cycling '74's, kept as a reference copy; images, navigation and footers are dropped.

| File | What it covers | When to read it |
|---|---|---|
| [live-object-model.md](live-object-model.md) | The LOM (Live 12.1): `Song`, `Song.View`, `Track`, `ClipSlot`, `Clip`, `Scene`, `MixerDevice`, `DeviceParameter`, `CuePoint` in full (children, properties with type and access, functions), every other class by one line, canonical paths for all classes | Before touching a Remote Script command: property names, which ones are settable, integer encodings of `clip_trigger_quantization`, `launch_mode`, `launch_quantization`, the note dictionaries of `get_notes_extended` / `add_new_notes` / `apply_note_modifications` |
| [live-python-enum-members.md](live-python-enum-members.md) | The Python member names of `Live.Song.Quantization`, `Live.Song.RecordingQuantization`, `Live.Clip.LaunchMode` and `Live.Clip.ClipLaunchQuantization`, which the LOM only shows as integers; compiled from Ableton's own control-surface scripts (not an Ableton page) | When the Remote Script needs an enum value rather than an int, e.g. `Live.Song.Quantization.q_quarter` |
| [live-api-overview.md](live-api-overview.md) | Live API concepts: object paths, root objects, canonical path and parent, ids, children, properties, functions, datatypes, notifications | When a LOM path or a "canonical parent" question comes up |
| [live-manual-launching-clips.md](live-manual-launching-clips.md) | Launch modes (Trigger, Gate, Toggle, Repeat), Legato, clip launch quantization and its relation to global quantization, velocity, nudging, Follow Actions | Designing anything that fires clips or scenes live |
| [live-manual-session-view.md](live-manual-session-view.md) | Session View: clips, tracks and scenes, scene tempo and time-signature settings, Scene View, recording, the crossfader | Scene tools, scene names that carry tempo, crossfader tools |
| [live-manual-recording-new-clips.md](live-manual-recording-new-clips.md) | Arming, recording into Session and Arrangement, overdub, count-in, record quantization, Capture MIDI | Capture and recording tools |
| [live-manual-clip-view.md](live-manual-clip-view.md) | The Clip View: clip properties, loop/region, warp and RAM mode, launch controls, the MIDI clip's Notes settings | Any clip property the LOM names but does not explain |
| [live-manual-editing-midi.md](live-manual-editing-midi.md) | The MIDI Note Editor (Live 12 chapter "Editing MIDI", successor of "Editing MIDI Notes and Velocities"): notes, velocities, probability, note operations, quantizing, multi-clip editing | Note-editing semantics: velocity, release velocity, probability, deactivated notes |
| [live-manual-midi-tools.md](live-manual-midi-tools.md) | Live 12 MIDI Tools: Generators and Transformations, their parameters | Before generating or transforming notes in a clip |
| [live-manual-midi-and-key-remote-control.md](live-manual-midi-and-key-remote-control.md) | MIDI and key mapping, takeover modes, mapping clip launch to notes and keys | Anything that competes with the user's own MIDI mappings |
| [live-manual-midi-fact-sheet.md](live-manual-midi-fact-sheet.md) | Ableton's MIDI timing model: latency vs jitter, timestamps, what to expect from recording, playback and playthrough | Reasoning about timing claims |

## How to refresh

Re-fetch the URL in the file's `Source` row (the Ableton manual now lives under `https://www.ableton.com/en/live-manual/12/<slug>/`; `https://www.ableton.com/en/manual/<slug>/` still serves the same page), convert the chapter content to Markdown (headings, lists, tables, parameter names and enum members verbatim; images, navigation and footers dropped), replace the file body, and update the `Fetched` date and the `Live version documented` row to what the page states. For the LOM, keep the same set of full classes and regenerate the "Other classes" list; the version is the line "This document refers to Ableton Live version N" on the page. Do not paraphrase.
